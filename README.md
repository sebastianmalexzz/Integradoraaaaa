# UniBot - Sistema Asesor Académico

Proyecto de **Algoritmos y Programación I** de la Universidad Icesi.

## Descripción

UniBot es una propuesta de sistema asesor académico para estudiantes de primer ingreso. El sistema busca identificar la carrera del estudiante y restringir las respuestas del asistente virtual a los temas permitidos para su programa académico.

## Primera entrega

En esta primera fase se realizó:

- Caracterización del sistema.
- Definición de objetivo, entradas, procesos, salidas y subsistemas.
- Elección de Scrum como marco de trabajo.
- Organización del proyecto por Sprints.
- Product Backlog inicial.
- Historias de usuario principales.
- Diagrama UML de casos de uso.
- Tablero Kanban inicial.
- Reflexión sobre el uso de IAG.
